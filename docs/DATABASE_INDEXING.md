# DATABASE INDEXING STRATEGY & PERFORMANCE

This document details the PostgreSQL indexing strategy implemented for MediVault, justifying each index against target query workloads, write overhead, and performance benefits.

---

## 📋 Index Matrix

| Table | Index Name | Columns Indexed | Target Query / Endpoint Supported | Justification & Expected Benefit | Write Overhead |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **`users`** | `idx_users_email` | `LOWER(email)` | `POST /api/auth/login`, `findByEmail` | Case-insensitive fast user lookup during login authentication (`O(log N)` vs `O(N)` full table scan). | Negligible (users table is low volume). |
| **`medicines`** | `idx_medicines_name` | `name` | `GET /api/medicines`, Product search | Accelerated catalog sorting and substring filtering. | Low (bulk CSV imports update index). |
| **`medicines`** | `idx_medicines_batch` | `batch` | Inventory audits | Fast batch number filtering. | Low. |
| **`medicines`** | `idx_medicines_expiry` | `expiry` | Expiry warning alerts | Enables range scans (`WHERE expiry <= threshold`) for dynamic Near Expiry badges. | Low. |
| **`sales`** | `idx_sales_date` | `date` | `GET /api/reports/sales` | Fast date range filtering (`WHERE date BETWEEN $1 AND $2`). | Low. |
| **`sales`** | `idx_sales_txn_ref` | `transaction_ref` | POS Payment verification | Immediate lookup by payment reference number (`TXN-UPI-XXXXXX`). | Low. |
| **`sales`** | `idx_sales_created_by` | `created_by` | Staff sales audit | Filters sales generated by specific cashier/user. | Low. |
| **`sale_items`** | `idx_sale_items_sale_id` | `sale_id` | `GET /api/sales/:id`, Join queries | Eliminates full table scans when aggregating invoice line items (`LEFT JOIN sale_items ON sale_id`). | Medium (every POS sale inserts rows). |
| **`sale_items`** | `idx_sale_items_medicine_id` | `medicine_id` | Sales analytics per product | Quick identification of sales history per product SKU. | Medium. |
| **`audit_logs`** | `idx_audit_logs_user_id` | `user_id` | Admin audit filters | Filters user activity logs by user ID. | Low. |
| **`audit_logs`** | `idx_audit_logs_action` | `action` | Audit log action filters | Filters audit events by event tag (`PROCESS_SALE`, `RESET_DATABASE`). | Low. |
| **`audit_logs`** | `idx_audit_logs_created_at`| `created_at` | `GET /api/audit-logs` | Supports `ORDER BY created_at DESC LIMIT 100` without full table sort. | Low. |
